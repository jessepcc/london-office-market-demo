# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Landlords, asset managers and people exploring an AI research PoC for the London office market.

## Product purpose

Show how public market evidence can support a dated briefing and independent research chat. Visitors should understand the mechanism and limits, watch real recorded examples and try the Python app.

## Capabilities and constraints

The public demo runs on demand. It has synthetic credential-free examples and live mode using visitor-supplied OpenRouter and Tavily keys. No shared passcode, scheduler or owner-funded API calls. The landing page lives on GitHub Pages. The Python app is prepared for free Streamlit hosting. Each visitor uses temporary, isolated session data.

## Brand commitments

The user selected a more visual project landing page instead of preserving the presentation layout. Retain the presentation's business content, dated real walkthroughs, sources and limits. Use plain demo framing.

## Evidence on hand

The site includes locally hosted recordings of the actual report and chat interface from 11 October 2026. They show an earlier interface, historic reviewed material, partial research and a stopped follow-up. These are not current market data or a promise of future results.
